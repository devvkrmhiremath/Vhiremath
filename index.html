Clari & Salesforce Agent

MCP built from scratch

An agentic assistant wired into Clari and Salesforce that answers questions across call recordings and CRM data, cross-referencing both. It runs on a manager pattern — one agent plans the approach and delegates, another executes the actual retrieval. Clari doesn't ship an MCP server, so I built one myself with FastMCP on top of Clari's REST API, giving the agent (and anything else that needs it) direct access to Clari data.

UAT Test Case Generator

0→1 no uat workbook existed before

Upload the transcript of a customer call, and a sequential agent (built on Microsoft Agent Framework) picks out the products that came up, searches the knowledge base, drafts the requirements, and generates test cases as a ready-to-use workbook.
